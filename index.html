02 About

I like small, sharp tools that do one thing well. Most of my work lives in a browser tab, a git repo, or a DNS zone file — not in a database that somebody else has to keep alive for me.

This page makes zero third-party requests. The type is the system font, the graphics are CSS, and the only network hop after DNS is the one that served this HTML.

  • No trackers, no cookies, no analytics
  • Comfortable on a phone with a bad connection
  • The domain is portable — move it anywhere, any time
